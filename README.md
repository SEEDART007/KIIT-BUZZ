## Features

- Create and share posts
- View and interact with other users’ posts
- User profiles with avatar
- Simple and intuitive UI

---

## Tech Stack

- Frontend: React.js
- Backend: Node.js / Express.js
- Database: MongoDB
- Authentication: JWT
